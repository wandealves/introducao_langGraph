# Introdução ao LangGraph: Orquestrando agentes com fluxos baseados em grafos

Este projeto demonstra como utilizar o LangGraph, uma extensão do LangChain, para construir fluxos de execução orientados a grafos para LLMs e agentes. Com o LangGraph, é possível criar aplicações onde o fluxo depende do estado atual da execução, decisões do agente ou resultados intermediários.

## 🔍 Sobre o Projeto

A construção de aplicações com Large Language Models (LLMs) evoluiu rapidamente. Frameworks como LangChain nos deram as ferramentas para conectar LLMs com fontes externas, memória e agentes capazes de tomar decisões. À medida que a complexidade dos fluxos aumenta, surge um desafio comum: como orquestrar o comportamento dos agentes de forma flexível, controlável e com lógica mais rica que simples pipelines lineares?

O LangGraph permite construir fluxos de execução orientados a grafos, onde você define nós (nodes) e arestas (edges) que representam o comportamento dinâmico do sistema.
